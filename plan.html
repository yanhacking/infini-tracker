Architecture de la plateforme INFINI

Boutique de bougies de luxe — édition Or Massif

Contexte

INFINI est une plateforme e-commerce sur-mesure construite pour vendre des bougies de luxe, avec une exigence centrale : zéro contenu codé en dur. Tout ce que voit le client (textes, photos, vidéos, pages, produits) est géré depuis un panel d'administration, sans intervention du développeur.

Le frontend est une expérience cinématique (défilement piloté par vidéo, façon Apple), et le backend est une API REST PHP/MySQL conçue dès le départ pour supporter la croissance de la marque sur plusieurs années.

Stack technique

PHP 8 + PDO MySQL API REST versionnée (/api/v1) Vite + JavaScript vanilla GSAP + ScrollTrigger Lenis (smooth scroll) Stripe PayPal Goshippo

Architecture

infini/ ├── api/v1/ → API REST PHP (produits, commandes, auth, paiement, expédition) │ ├── src/Controllers/ → logique des routes │ ├── src/Models/ → accès base de données (PDO) │ ├── src/Services/ → Stripe, PayPal, Goshippo, optimisation média │ └── database/ → schéma complet + données de départ │ ├── admin/ → Panel d'administration (rôles, CMS, produits, commandes) │ └── infini-cinematic/ → Site public (expérience cinématique, panier, compte client)

Base de données

Le schéma couvre dès aujourd'hui l'ensemble des besoins prévus, pour ne jamais avoir à re-migrer en cassant l'existant :

Catalogue

Produits, variantes, catégories, médias, notes olfactives

Comptes & rôles

Clients, adresses, administrateurs (super admin / admin / gestionnaire)

Commandes

Commandes, articles, historique complet des statuts

CMS

Pages en blocs, réglages globaux, bibliothèque média

Marketing

Avis clients, liste de souhaits, newsletter, coupons

Observabilité

Journal d'activité admin, statistiques internes, tentatives de connexion

Paiement & Expédition

  • Stripe — Payment Intents créés côté serveur, montant jamais confié au navigateur ; confirmation finale uniquement via webhook signé.
  • PayPal — Orders API v2, capture sécurisée, webhook vérifié par signature.
  • Goshippo — Au moment du paiement, le client voit tous les tarifs de tous les transporteurs disponibles pour son adresse ; une fois payée, l'étiquette est achetée automatiquement et le suivi apparaît dans son espace client.

Sécurité

Appliquée à chaque couche, pas comme une étape à part : requêtes préparées partout (aucune injection SQL possible), mots de passe hashés, jetons CSRF sur les formulaires admin, limitation des tentatives de connexion, en-têtes de sécurité HTTP, et un journal d'activité qui trace chaque action administrative.

Phasage

Le projet est livré par phases pour rester maîtrisable et vérifiable à chaque étape — voir le détail et l'avancement en temps réel sur la page de suivi.
